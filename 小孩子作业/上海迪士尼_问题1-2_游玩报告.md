## 二、问题1：最短步行路线（从出入口出发并回到出入口）
### 1）题意
从出入口开始、到出入口结束，且只游玩：宝藏湾、梦幻世界、明日世界、奇想花园、探险岛（共5个主题乐园），求步行时间最短路线。

### 2）结果（最短总步行时间：40分钟）
最短路线之一为：

- 出入口 → 明日世界 → 奇想花园 → 梦幻世界 → 宝藏湾 → 探险岛 → 出入口

分段步行时间：

| 路段 | 步行时间 |
|---|---:|
| 出入口 → 明日世界 | 11分钟 |
| 明日世界 → 奇想花园 | 7分钟 |
| 奇想花园 → 梦幻世界 | 4分钟 |
| 梦幻世界 → 宝藏湾 | 5分钟 |
| 宝藏湾 → 探险岛 | 4分钟 |
| 探险岛 → 出入口 | 9分钟 |
| **合计** | **40分钟** |

> 说明：该问题属于“访问多个点并回到起点的最短路”类型（类似旅行商问题）。在图上给定步行时间后，对所有路线进行比较即可得到最短路线。反向走同样最短。

## 三、问题2：一家三口（小孩145cm）一日游计划（含巡游+幻影秀）
### 1）规划原则
1. **先热门后补齐**：早上优先排队长的项目（创极速光轮、矿山车、飞越地平线等）。
2. **满足“每园≥1项目”**：宝藏湾/梦幻世界/明日世界/奇想花园/探险岛/玩具总动员各至少1个项目。
3. **演出提前占位**：巡游与幻影秀各提前约30分钟。
4. **减少走路**：整体行走顺序参考问题1的最短环线，并把“玩具总动员”插入在相邻时段（明日世界附近/中午后时段）。

### 2）推荐项目清单（覆盖全部园区）
- 明日世界：创极速光轮（122cm+）或 巴斯光年星际营救（全身高）
- 梦幻世界：七个小矮人矿山车（97cm+）或 小熊维尼历险记（全身高）
- 奇想花园：幻想曲旋转木马（全身高）或 漫威英雄总部（全身高）
- 探险岛：飞越地平线（全身高）或 雷鸣山漂流（107cm+）
- 宝藏湾：加勒比海盗（全身高）
- 玩具总动员：弹簧狗团团转（全身高）或 抱抱龙冲天赛车（107cm+）

> 小孩145cm：以上身高要求均满足，可全家同玩。

### 3）一日游时间表（含两种“幻影秀场次”方案）
#### 白天主线（两种方案通用）

**方案A（看20:00场）**

- 20:00–20:20 观看奇梦之光幻影秀
- 20:20–21:30 结束后：补短队项目/商店/拍照

**方案B（看21:15场，通常更利于多玩项目）**
- 19:00–20:30 继续补项目（可回梦幻世界/明日世界刷短队或购物）
- 20:45 到奇想花园占位
- 21:15–21:35 观看奇梦之光幻影秀
- 结束离园
